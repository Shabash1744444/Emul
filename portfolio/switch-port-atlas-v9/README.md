# Switch Port Atlas v9

Интерактивный HTML-каталог проектов, портов и материалов для Nintendo Switch.

Публикуется исходный `switch_port_atlas_v9_full.html`, переименованный в `index.html` для статического хостинга. Разметка, логика, поиск и ссылки не изменены.

Каталог содержит 775 записей по исходной проверке. Внешние ссылки предоставлены для справки: их актуальность и доступность зависят от третьих сторон. Игровые файлы в публикацию не включены.
