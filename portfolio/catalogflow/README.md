# CatalogFlow — демонстрационный каталог

Обезличенная версия инструмента поиска номенклатуры с оригинальной компоновкой и механизмами обработки данных. Все 96 встроенных товарных позиций, остатки и резервы вымышлены.

[Открыть демоверсию](https://shabash1744444.github.io/Emul/portfolio/catalogflow/)

## Проверка
- **Найти:** один клик выполняет поиск по введённому артикулу, названию или строке клиента. **Двойной клик или два быстрых касания** кнопки «Найти» включают или выключают автопоиск по мере ввода; активный режим отмечен цветом.
- Под заголовком доступна компактная строка с кнопками **«Один артикул»** и **«Три артикула»**. Это встроенные тестовые запросы для обычного и массового поиска.
- **Резерв**, **0**, **Порядок ввода**, сортировка по столбцам, копирование и экспорт CSV/XLSX работают через оригинальную логику.
- Загрузка собственного каталога поддерживает CSV, XLS/XLSX/XLSM и JSON. Каталог хранится локально в IndexedDB. После «Очистить память» обновите страницу для возврата демоданных.

## Архитектура и ограничения
Поиск по алиасам и поддержка подключаемых папок сохранены в коде, но служебная панель алиасов скрыта **только в публичном интерфейсе демо**. Базовые функции поиска, сортировки, фильтров, импорта и экспорта не удалены.

Интерфейс сохраняет размеры элементов и компоновку исходной программы; заменены фирменное оформление, логотип и товарные данные. На телефоне таблица прокручивается горизонтально, как в оригинале.

Для чтения Excel-файлов используется SheetJS из CDN. Лицензия намеренно не назначена.
