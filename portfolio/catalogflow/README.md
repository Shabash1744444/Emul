# Демо-каталог — поиск номенклатуры

Обезличенная версия исходного рабочего интерфейса: синий цвет вместо корпоративного, без названий компаний и внутренних данных. При каждом открытии загружается **96 полностью вымышленных позиций**, включая **6 с нулевым остатком**. В таблице по умолчанию показаны и остаток, и резерв.

[Открыть демо](https://shabash1744444.github.io/Emul/portfolio/catalogflow/)

## Как проверить
1. При открытии сразу отображается таблица из 96 позиций.
2. **«Один артикул»** — точное совпадение по коду; **«Три артикула»** — пакетная проверка нескольких строк.
3. **«Нулевой остаток»** — показывает шесть позиций с нулевым остатком. Нажатие **«0»** скрывает эти позиции (результат станет пустым); повторное нажатие возвращает их.
4. **«Все 96 позиций»** — возврат ко всей демонстрационной таблице.
5. **«Резерв»** — скрывает/отображает отдельный столбец резерва. **«Порядок ввода»** — переключает последовательность пакетных результатов. По столбцам доступны сортировка и копирование.
6. **«Найти»** — разовый поиск. **Двойной клик или два быстрых касания** — включение/выключение автоматического поиска по мере ввода.
7. Результаты можно копировать целиком или выгружать в CSV/XLSX.

## Реализация
- Поисковый движок, релевантность для свободного текста, альтернативные обозначения, поиск по алиасам, сортировка, фильтры, пакетный поиск, IndexedDB, импорт CSV/Excel/JSON и экспорт сохранены.
- Служебные кнопки загрузки/очистки в шапке **только скрыты в демо**. Обработчики и функциональность загрузки файлов остаются в исходном коде; пользовательский интерфейс демо всегда стартует с синтетическими данными.
- Панель алиасов сохранена, **свёрнута по умолчанию**, её можно раскрыть.
- Исходная компоновка и таблица сохранены; на узких экранах таблица прокручивается горизонтально.
- Excel поддерживается через внешнюю библиотеку SheetJS (CDN). Ни один товар, числовой остаток или резерв в демоверсии не отражает реальные данные организации.
