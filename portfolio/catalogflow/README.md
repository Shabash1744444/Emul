# CatalogFlow — демонстрационный каталог

Нейтральный интерфейс для поиска номенклатуры. В каталоге представлены только вымышленные товары и остатки.

Работают поиск, пакетные запросы, остатки и резерв, сортировка, импорт CSV/XLSX/JSON, поиск по алиасам и экспорт CSV/XLSX. Для Excel используется SheetJS по CDN.

Запуск: открыть index.html в браузере. Демонстрационные позиции показываются автоматически при отсутствии ранее загруженного каталога. Для сброса локальных данных используйте «Очистить память».

Оригинальные поисковые алгоритмы и интерфейсные механизмы сохранены; заменены брендинг и демоданные, восстановлены два ранее отсутствовавших вспомогательных обработчика из ранней версии программы.
