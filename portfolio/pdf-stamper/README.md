# PDF Stamper PRO — демонстрация работы с PDF

Браузерное приложение на HTML/JavaScript для предварительного просмотра PDF, размещения изображений отметок и пакетного экспорта. Приложение опубликовано без изменения алгоритмов оригинала. Используйте только свои документы и изображения.

На главной странице выберите PDF и тестовые изображения для подписи и печати. Файл `sample-document.pdf` содержит только вымышленные данные.

Зависимости pdf-lib, PDF.js и fontkit загружаются с CDN; при отсутствии доступа к ним приложение работать не сможет. Это не квалифицированная электронная подпись.
