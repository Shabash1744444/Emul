# PDF — подписи и печати

Браузерное приложение для предварительного просмотра PDF, размещения изображений подписи и печати относительно текстового якоря (строка из 5 и более символов подчёркивания), сохранения координат и пакетного экспорта. Исходный алгоритм обработки сохранён.

## Быстрая демонстрация
1. Откройте приложение и нажмите **«Запустить демо»**. Программа создаст вымышленный PDF и изображения подписи и печати с явной маркировкой DEMO/SAMPLE.
2. Дождитесь появления предпросмотра. Перетащите образцы подписи и печати мышью или пальцем, при необходимости настройте координаты.
3. Нажмите **«ПОДПИСАТЬ И СКАЧАТЬ»**. Результат скачивается в формате PDF.
4. Для пакетной демонстрации включите **«Проверить пакетную обработку (3 PDF)»** до запуска демо. Браузер может запросить разрешение на несколько загрузок.

Файл `sample-document.pdf` — отдельный вымышленный одностраничный PDF с корректным текстовым якорем для ручного теста. Для ручной проверки можно загрузить его и собственные тестовые PNG/JPG подписи и печати.

**Ограничение:** автоматическое обнаружение точки привязки рассчитано на PDF с текстовой линией `_____` и не применяется к произвольным сканам. Это не квалифицированная электронная подпись. Не используйте имитацию подписей или печатей для реального документооборота.

Файлы обрабатываются в браузере. Библиотеки pdf-lib, PDF.js и fontkit загружаются с внешних CDN, поэтому для работы требуется доступ к ним.
