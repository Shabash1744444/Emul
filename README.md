# Arcade Hub — браузерная платформа классических игр

Публичный экспериментальный проект: единая веб-оболочка для нескольких классических игровых систем, с поддержкой геймпада, графических эффектов и игровых режимов.

## Что реализует платформа
- Браузерный интерфейс для выбора и запуска поддерживаемых систем.
- Интеграция нескольких эмуляторных ядер на базе WebAssembly/JavaScript.
- Поддержка геймпадов и локальных сценариев игры.
- Графические эффекты с использованием WebGL.
- Экспериментальные сетевые функции; требования и совместимость уточняются для конкретных браузеров и режимов.

## Почему это интересно для портфолио
Сложный прикладной проект на стыке интерфейсов, WASM, мультимедиа, производительности и обработки пользовательского ввода. Показатель способности изучать незнакомые компоненты и доводить их до совместной работы.

## Запуск
Откройте [index.html](index.html) или демонстрационный сайт. Для некоторых игровых систем нужны пользовательские данные игр/ROM, которые должны использоваться законным способом. Эмуляторные ядра — сторонние компоненты; интеграция не означает авторство каждого ядра.

## Технологический подход
HTML / CSS / JavaScript, WebAssembly, WebGL, WebRTC. AI-assisted разработка; постановка задач, интеграция, тестирование и управление проектом — автор Arcade Hub.
